# Changelog

## v1.4 — Agri Nexus refinement

### Added
- Original cream / paper / olive / gold palette restored.
- Rebuilt interface shell with refined nav and dashboard cards.
- At-a-glance summary cards for insect, disease, weed and active ingredient records.
- Empty field collapsing for cleaner profile pages.
- Smarter search with broader keyword matching and route-based suggestions.
- A–Z quick navigation for active ingredient lists.
- PDF/print styling for export-ready documentation.
- Review-oriented data flags and review notes.

### Revised
- Moved interface hierarchy toward clearer differentiation between insects, diseases, weeds and active ingredients.
- Reduced visual clutter by hiding empty fields and showing compact unavailable summaries.
- Normalized section colors and stronger title hierarchy for print and digital clarity.

### Pending verification
- Scientific confirmation of all missing biology, signs and herbicide local names.
- Official IRAC / FRAC / HRAC validation for any group assignments in operational use.
- Explicit review of local product names and trade names before recommendations are relied on.

### Notes
This version intentionally separates generic reference material from operational recommendations. Data marked as review-only is not treated as a recommendation and should not be used for final agronomic advice without specialist validation.
