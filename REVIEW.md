# Review file

## Added / needs review entries

The following categories are intentionally left as review material and marked in the interface as review status where appropriate:

### Insects
- Family, definition, damage, life cycle, monitoring information, and threshold fields remain incomplete for many records.
- Group links are treated as taxonomic reference only and should not be considered species-specific recommendations.

### Diseases
- Signs were separated from symptoms where possible, but a specialist should validate which observations belong in the signs section.
- Disease cycle, infection conditions and some classification fields are intentionally blank.

### Weeds
- Local names such as shibit, abu rukbah, deniba and ajira require confirmation.
- Scientific names and family/life cycle details require specialist validation before being used operationally.

### Active ingredients
- Chemical family and the four non-classified groups remain under review.
- Classification status is preserved, and missing chemical group entries are not assumed to be absent.

### Operational guardrails
- All rates, PHI and REI values remain intentionally null.
- Official registration status is not assumed and remains unknown until a trusted source is reviewed.
- Recommendations are intentionally excluded from the database; only reference material is included.
